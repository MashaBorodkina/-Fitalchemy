## Тестовая документация для проекта
Этот репозиторий содержит тестовую документацию для анализа производительности сайта fitalchemy.me. Включает отчеты о тестировании, рекомендации по оптимизации и результаты анализа с использованием Google PageSpeed Insights.

## Содержание
1. Обзор тестирования
   * Цели тестирования
   * Используемые инструменты и методы
2. Результаты тестирования
   * Рейтинг производительности для мобильных и десктопных версий
   * Ключевые метрики
3. Выявленные проблемы и рекомендации
   * Оптимизация изображений
   * Минимизация JavaScript и CSS
   * Оптимизация пути рендеринга
   * Улучшение работы сервера
4. Заключение
   * Рекомендации по улучшению
